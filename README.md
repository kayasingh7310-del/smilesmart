# SmileSmart

SmileSmart is a responsive oral-health education website designed for teenagers.

## Features

- Interactive Smile Check with a score and recommendations
- Educational oral-health topic cards
- Interactive tooth anatomy explorer
- Sugar visualization tool
- Myth-versus-fact cards
- Responsive mobile navigation
- Local storage for saved scores
- Educational disclaimer

## Run the website

1. Download and unzip the folder.
2. Open `index.html` in a browser.

For a local development server, open the folder in VS Code and use the Live Server extension.

## Customize it

Replace the About section with your own name, motivation, research, and community impact. Add a GitHub link and contact information before including it in your college application.

## Important

The content is educational and should not be presented as medical diagnosis or treatment advice.
