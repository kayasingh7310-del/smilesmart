# SmartSmile

SmartSmile is a responsive, interactive oral-health education website created for teens.

## Included features

- Personalized Smile Score
- Daily habit tracker saved with local storage
- Achievement badges
- Learning topic filters
- Interactive tooth anatomy explorer
- Sugar calculator
- Food explorer
- Five-question oral-health quiz
- Two-minute brushing timer
- Rule-based educational assistant
- FAQ section
- Meet the Creator, Mission, and Vision sections
- Contact form and direct email link
- Dark mode
- Responsive mobile design
- Educational disclaimer

## Publish with GitHub Pages

1. Download and unzip the project.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to the root of your GitHub repository.
3. Open the repository's **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, and choose `/ (root)`.
5. Save and wait for GitHub Pages to update.

## Important limitation

The SmartSmile assistant is a rule-based educational demo. It does not use an AI API and does not diagnose or provide personalized medical treatment.
